# 260224-ViT
Vision Transformer fine-tuning toy project!

## Dataset
I made my own dataset wandering around Sogang University, South Korea   
4 classes:
- building-in
- building-out
- road
- nature

Will my ViT model predict well of those 4 classes ?! (~ing)

## Model
- vit_b_16 (ImageNet pretrained)
- input size: 224x224
